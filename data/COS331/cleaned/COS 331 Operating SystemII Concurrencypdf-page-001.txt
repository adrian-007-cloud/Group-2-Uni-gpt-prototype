1.0 INTRODUCTION
Concurrency
Permit us to throw some light on the following two terms: Concurrency and parallelism that are associated
with computer jobs execution.
Concurrency means executing multiple tasks at the same time but not necessarily simultaneously. The term
concurrency is usually achieved in a uniprocessor system. In a single-core environment, concurrency is
achieved via a process called context-switching. If it's a multi-core environment, concurrency can be
achieved through parallelism.
Parallelism is concerned with utilizing multiple processors/cores to perform two or more tasks
simultaneously. Parallel computing in computer science refers to the process of performing multiple
calculations simultaneously. This can only be achieved in a multiprocessor system.
 In a single-core environment, concurrency happens with tasks executing over the same time period
via context switching. i.e., at a particular time period, only a single task gets executed.
 In a multi-core environment, concurrency can be achieved via parallelism in which multiple tasks
are executed simultaneously.
Parallel processing or parallelism is being widely used in computer architectures ranging from
supercomputers to workstations, because of its promise of high performance at a relatively low cost.
